# Models directory

This folder is populated automatically when you run the training
scripts — nothing here needs to be created by hand.

Generated by src/preprocessing.py (via any train_*.py script):
  - preprocessing_pipeline.pkl
  - feature_order.json

Generated by each train_*.py script:
  - logistic_regression_model.pkl
  - random_forest_model.pkl
  - xgboost_model.pkl
  - lightgbm_model.pkl        <- deployed model, used by app/app.py
  - catboost_model.pkl
  - neural_network_model.pkl
  - model_metrics.json        <- appended to by every train_*.py script
